# Konzepte und Quellen

Diese Unterlagen erklären Herkunft und spätere Vision. Für die tägliche Entwicklung genügen [Entwicklungsstart](../DEVELOPMENT.md), [MVP](../MVP.md) und die aufgabenbezogenen Referenzen.

| Dokument | Nutzen |
| --- | --- |
| [Projektvision](PROJECT_VISION.md) | Problem, Begriffe, fachliche Beispiele und spätere Ausbaustufen. |
| [Quellen und Entscheidungen](SOURCES_AND_DECISIONS.md) | Herkunft, Gültigkeit, abgelöste Aussagen und Verweise auf offene Entscheidungen. |

Originalkonzepte können hier nur nach Prüfung auf öffentliche Eignung ergänzt werden. Das ursprüngliche Konzept-PDF enthält Personen- und Buchungsdaten und bleibt ausserhalb dieses öffentlichen Repositorys. Die Zusammenfassung erhält den entwicklungsrelevanten Kontext.
